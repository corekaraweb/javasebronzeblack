Oracle認定Javaプログラマ Bronze SE（試験番号：1Z0-818-JPN）の合格、およびJava言語における高度な言語仕様の深い理解を目的とした学習ソースコード一式を管理するリポジトリです。
本リポジトリ内のコードは、『徹底攻略Java SE Bronze問題集［1Z0-818］対応　（通称：黒本）』の解説・サンプルコードをベースに、自身で検証・拡張したプログラムで構成されています。

## 1. 学習の背景と目的
現在、サーバーサイド言語やクラウドなどモダンIT技術を習得中です。
すでに実務経験のあるWeb制作（WordPress/HTML/CSS/PHP）のスキルに加え、バックエンドの「堅牢な型システム」や「メモリ管理」「オブジェクト指向の高度な設計」を習得するため、Java Bronze SEの学習に挑戦しました。

単なる資格取得（暗記）に留まらず、**「なぜこの挙動になるのか」「どのような例外が発生し得るのか」**をコードレベルで検証し、実務でバグの少ないクリーンなバックエンドコードを書くための土台を築くことを目的としています。

## 4. 特に深く注力して検証した技術トピック

### ① 参照型変数と配列におけるメモリ挙動の検証

基本データ型（プリミティブ型）と参照型（オブジェクト、配列）の「値渡し」の挙動の違いを検証。

配列変数を別の配列変数に代入した際、インスタンスそのものがコピーされるのではなく「参照（メモリ上のアドレス）」がコピーされ、同じ実体を指すことで起きる意図しない値の書き換え問題などをコードレベルで実証しました。

### ② カプセル化による情報隠蔽と不適切なインスタンス化の防止

フィールド変数を private 修飾子で隠蔽し、適切な getter / setter を通じてのみデータにアクセスさせる設計を実装。

コンストラクタを多重定義（オーバーロード）し、不完全なデータを持ったオブジェクトが生成されるのを防ぐためのバリデーションロジックなどを記述・検証しました。

### ③ 継承と多態性（ポリモーフィズム）の活用

親クラスで共通の振る舞いを定義し、子クラスでそれを extends して固有の処理を Override（再定義）する流れを実装。

実行時に「親クラスの型」の変数に「子クラスのインスタンス」を代入し、同一のメソッド呼び出しでありながら動的に適切な子クラスの処理が呼び出される、オブジェクト指向の強力な特性（多態性）を実証クラスにて検証しました。
